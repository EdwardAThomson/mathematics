# mathematics

Public mathematics research and write-ups.

## large-numbers/

How much does it actually cost, in pure logic, to name a huge number?
Measuring and mechanically verifying (in Lean 4) the real specification
cost behind number-naming systems like Rayo's function — from a small-n
naming table through two independently rigorous constructions of the
self-reference trick that makes such numbers large in the first place. See
[`large-numbers/README.md`](large-numbers/README.md) for the full write-up.
